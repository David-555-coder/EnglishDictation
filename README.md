# 英文文章智能默写 · 使用说明

完全离线的 Windows 学习工具。第一次在完整文章中回忆英文；手动交卷后统一批改；之后只复习错词所在的原句。程序不会上传文章，也不使用 AI API。

## 1. 启动与保存

双击 `EnglishDictation.exe`，不需要安装 Python，也不需要联网。

主目录的 `EnglishDictation.exe` 用于日常启动，`start.bat` 也会优先启动这个文件，继续使用原来的 `data`。无需重新导入。`src`、`tests`、`tools`、`packaging_hooks` 和打包配置保留供后续维护。

### 从 GitHub 获取与源码运行

在仓库页面选择 **Code → Download ZIP**，解压后双击 `EnglishDictation.exe`。仓库仅提供软件，不包含个人文章库、答题记录或学习备份；首次使用时自行导入 Word 文章。

如需从源码运行，安装 Python 3.11 或以上版本，在项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

本地 `data`、日志、备份、构建产物和个人 Word 文件已由 `.gitignore` 排除，仍保留在本机。更新软件时请保留自己的 `data` 文件夹。

请把 EXE 放在可写的普通文件夹中使用。学习数据默认在 EXE 同级的 `data`，日志在 `logs/app.log`。如果程序目录不可写，则使用 `%LOCALAPPDATA%/EnglishDictation` 下的 `data` 和 `logs`。

- 文章导入后，保存识别结果和一份本地 Word 副本。下次启动不用再导入；成功导入后，即使原文件移动，仍可学习和导出。
- 输入停止约 0.6 秒后自动保存草稿；切换文章、提交、关闭时也会保存。正常保存保持安静，只有保存失败才显示提醒。重开程序自动恢复最近一轮未完成练习。
- 程序自动保存最近更新的10篇未完成文章，从“练习 → 未完成练习…”明确继续；同篇多轮只显示最近一轮，已有同篇旧草稿不合并、不直接清空。超过10篇只清理最旧文章的整篇默写草稿，不删除文章、错词或正式成绩。错词/今日复习草稿仍按原有最近10轮规则独立保留，启动及切换文章的恢复规则不变。
- 不要只搬走 EXE：换文件夹或换电脑时，请把 `data` 一起复制，或使用备份功能。
- 意外断电或强制结束可能丢失最后不到一秒尚未落盘的输入；正常关闭会保存。
- 同一份数据只允许一个程序窗口运行，避免互相覆盖草稿。

## 2. 导入与整理文章

1. 点击顶栏“导入”，选择“导入文章”可一次选多个 `.docx` 或旧式 `.doc`；选择“导入文件夹”则导入该文件夹内的 Word，不递归子文件夹。`.doc` 会在本机通过 Microsoft Word 转换成程序内部的 `.docx` 副本，原文件始终只读且不会被覆盖；电脑未安装 Word 时会给出中文提示。
2. 导入在后台进行，有进度提示。一个损坏文件不会阻止其他文件导入。
3. 左侧显示文章数、总重点词数和每篇重点词数，按文件名自然顺序排列，例如 `djc2` 在 `djc10` 前。
4. 可按文件名搜索；长文件名可悬停查看完整名称和来源路径。
5. 选中文章后，点“从列表移除”、按 Delete 或右键移除。确认后移除该文章及其草稿，但不会删除原 Word、学习历史或长期错词。缓存副本暂时保留，便于安全恢复。

支持拖动框选、Ctrl 点选不连续文章、Shift 选择连续范围。右键已选中的任意文章，选择“从列表移除选中的 N 篇文章”，也可点左侧底部“移除选中 N 篇”或按 Delete。一次确认、整批保存；发生数据库错误时不会只移除一半。搜索隐藏的文章不在移除范围内。

快速切换时会等待约 0.13 秒，仅读取最后选中的文章；多选整理期间不自动逐篇打开。原文预览改为按段落排版，保留红色加粗、中文释义、换行和可选中文字。

旧版只保存了路径的文章，在第一次启动新版时会尝试读取原文件并建立副本。如果提示找不到文件，请找回原文件或重新导入。

修改外部 Word 不会自动改变已保存题目。要使用修改后的 Word，请先备份数据，再移除该文章并重新导入；该文章草稿和手动调整会重置，历史记录仍保留。

## 3. 挖空规则与手动调整

程序提供三个固定预设，默认使用标准模式。中文、标点、普通文字均保留；Word 的标题/Heading 样式默认不挖空。

- **标准模式（推荐）**：英文为红色或加粗，并且后面紧邻中文释义。
- **宽松模式**：不看颜色和粗体，只要英文紧邻中文释义就挖空。无格式短语的边界本身存在歧义，程序优先使用 Word run 边界；仍有少数识别不准时用“手动调整挖空”合并。
- **严格模式**：英文必须同时是红色且加粗，可以没有中文释义。

支持单词、连字符词、带撇号的词和完整短语；支持相邻 run 合并、圆括号/方括号中文释义和紧邻的中文注释。读取正文、表格文字、超链接显示文字，不访问链接。红色根据实际 RGB 或文档主题颜色判断，并考虑常见样式继承。

顶部“文章与设置”提供：

- **本篇识别规则**：在标准、宽松、严格三个预设中选择，对当前文章重新识别。
- **默认识别规则**：仅影响之后新导入的文章，不改已有文章。
- **手动调整挖空**：选择段落，选中英文后点“将选中英文设为一题”；在下方选题可取消挖空。框选完整短语可合并；拆分则先取消原题，再分别选择。

这些修改只保存在软件里，不修改原 Word。重新识别会重置本篇手动调整，操作前会提示。旧草稿保留原来的题目，新练习使用新规则。

普通正文样式的标题无法仅凭外观百分之百识别；若误挖，请手动取消。默认要求中文释义也可减少误判。

## 4. 第一次整篇默写

1. 选中文章，先用“原文”检查识别结果，重点英文显示红色加粗。
2. 点击右侧“学习状态”中的蓝色“开始默写”，显示完整文章，上下文、段落、换行、中文提示继续可见。
3. 填写英文。期间只显示填写进度，不显示对错或正确率。
4. 全部填完后仍可修改，不会自动提交。
5. 主动点击右侧蓝色“提交批改”。有空白会再次确认；确认提交后，空白算错误。

默写期间点“原文”（Ctrl+1）会先保存本轮输入，再切换原文，不会因为有草稿而拒绝查看。原文页右侧恢复为单一“开始默写”，Ctrl+2 同样开始新一轮；已有未完成练习时保留确认提醒，取消不会新开，也不清空旧草稿。继续已有输入请打开“练习 → 未完成练习…”，选中文章双击或点击“继续练习”，恢复答案和位置。仅查看原文不会产生草稿；全部填完但未提交仍算未完成。切换文章和启动时的自动恢复规则不变。

答案比较忽略大小写、首尾空格、多余连续空格和常见弯直撇号差异，但不会自动修正拼写。例如 `Ambition` 正确，`ambitious` 错误。

提交后锁定本轮答案：绿色为正确、红色为错误；错误输入框旁完整显示正确答案，文章下方还有本次错词汇总。右侧显示正确数、错误数、未填写数、正确率。

如果数据库暂时写入失败，会提示“成绩待保存”。保持窗口打开，点击右侧主按钮“重试保存成绩”；同一轮不会重复累计。

“显示答案”只控制答案提示的显示与隐藏，无需确认，不标记学习记录，不影响成绩、错词统计或复习阶段。可以先看答案、隐藏后再默写，所有结果只按最终提交的内容计算。继续未完成练习时答案默认隐藏。旧版本的查看标记保留兼容，但不再展示或参与计算；历史成绩和复习状态不追溯改写。

## 5. 错词复习：只练薄弱的句子

有两个入口：

- **只练本轮错词**：交卷后点右侧按钮，只生成刚才仍然写错的词。再提交后继续点，就会逐轮缩小范围，直到全对。
- **历史错词练习**：打开历次有错词的提交记录，双击一条，或选中后点“开始练习”。可按完成时间或文章自然顺序排序；支持拖动、Ctrl、Shift 多选，并可通过右键、按钮或 Delete 批量删除记录。退出程序后未删除的记录仍保留。

进入错词复习后，程序会先显示一遍**带完整正确答案的错词原句**，目标词以红色加粗显示。阅读完成后点击右侧“开始错词默写”，才会把这些目标词换成输入框。这个准备预览不显示整篇文章，也不单独计算成绩。已经开始并自动保存的错词草稿，重开时会直接继续填写。

例如原句 `The extensive research gained momentum.` 中只有 `momentum` 写错，复习时显示 `The extensive research gained [输入框].`，不会显示文章其他句子。

同一句中两个目标都错，会在一句内同时挖空；答对的目标正常显示。错词复习同样必须手动统一提交，不会即时反馈。

如果原文已从文章列表移除，历史错词仍能依据快照练习；但“开始整篇默写”和 Word 导出需要先导入完整文章。

## 6. 长期错词本与学习历史

点“错词本”可查看跨文章归并的词条，默认按字母排序，也可按错误次数或最近错误排序。支持搜索英文、中文，Ctrl/Shift 多选。

- “练习选中错词”：每个词选取一条保存的错误例句，组成句子复习。
- “练习全部错词”：练习整个错词本，不受当前搜索过滤影响。
- 展示相邻的英文、中文、错误次数、最近错误、来源、记忆状态和复习安排。最近错误在表中显示简短日期，悬停可看完整时间；较长英文最多占三行。正确后不会擅自删除长期错词。
- 删除选中错词、清空错词本都需要确认。清空删除长期词条及例句，不删除历史成绩。
- “练习”菜单恢复为“开始默写”“提交批改”，仅新增“未完成练习…”；“原文”和“显示/隐藏答案”继续在主工具栏，工具栏隐藏时可从“视图”重新显示。顶栏“历史错词练习”（Ctrl+R）继续提供有错词的历史练习入口，已有学习历史完整保留。

错误次数按实际错误答题记录累计。同一词在一轮出现多次并写错多次，会累计多次。当前没有统计整个文章库的总出现次数。

### 今日复习

顶部“错词本”旁的“今日复习（X）”显示今天已安排且尚未完成的词数。默认每日上限40词/短语，在“文章与设置 → 每日复习数量”可选20、40、60、80词；到期词不足时只安排实际数量。开始当天练习前调整立即生效，开始后（包括保存草稿或已完成）修改从明天生效，不删除今天任务或输入。不同文章的到期词混合练习，沿用现有中文提示、英文填写、快捷键和统一批改。

按钮悬停提示、完成后的状态栏以及点击“今日复习（0）”的提示，会区分今日已完成数量和另外到期待安排的数量。“0”不代表积压已清空。错词本将已选入今日任务的词显示为“今日待复习”，其余已到期词显示为“到期待安排”；悬停可查看原定日期和已等待天数。未安排的词继续保留，显示文案不改变抽取顺序、每日上限或复习日期。

普通练习答错后加入现有错词本，首次安排明天到期。完成到期的“今日复习”并答对，按3、7、14、30天延长间隔，之后保持30天。到期的旧错词若在普通整篇默写中全部答对，且最近错误和上次有效复习均早于当天，也按一次有效复习处理；当天只计一次。若该词已在今日任务里，会同步标记完成，不补抽新词。初学阶段答错回到1天；已进入7天及以上间隔后答错，保留阶段并标记“待确认”，次日到期。确认复习答对降一档恢复（7→3、14→7、30→14天），确认仍答错回到1天；确认答对不同时升级。到期不保证当天必定抽中，仍受每日上限限制。

查看答案不影响判分或上述规则。手动“历史错词练习”“练习选中/全部错词”答对不提升长期阶段；普通整篇默写只在满足上述到期与跨日条件时计入复习。其他练习再次答错会提前复习：熟悉词进入待确认，初学词回到初始阶段；不会推迟已有到期日期。同一天重复手动答错不会消耗确认机会。若旧的今日复习草稿在整篇默写后继续，已完成的词会从待答题目中移除，其余已填答案保留。

每日名额约70%先取最早到期词（同日到期再比较错误次数、最近错误），其余约30%依次安排：已到期的待确认词、初学阶段的近期错词、其他近期错词。待确认词按最早到期优先，不受近7天限制，等待较久也不会退出优先组。初学阶段指当前1天或3天间隔；近期指今天及前6个日历日发生错误，且最近错误日期不早于上次长期复习日期，组内先比较最近错误，再比较错误次数和到期日期。两部分去重，不足由最早到期词补齐；不提前抽取未到期词，也不突破每日上限。现有当天任务保持固定，不因升级重排；新顺序用于以后新生成的任务。未选中的词保持原到期日期和阶段。当天草稿可继续，跨日旧草稿仍可保存成绩，但不推进长期阶段，请从“今日复习”进入当天任务。按钮每分钟以及点击、交卷、关闭错词本后刷新。

分配比例用于兼顾近期错误，并不保证所有词按时复习或更快清空积压。积压很多时，为近期错词预留名额会降低旧词的处理速度；数量设置保留用户选择，不会自动加量。

升级前自动备份旧数据库到 `data/migration_backups/`，增量增加确认状态和每日计划设置字段，不改已有学习记录。升级前已生成的当天任务保持固定，避免影响旧草稿。尚无复习日期的历史错词按错误次数、最近错误排序，从升级次日起每40词分配到一个日期，不会全部同时到期。错词本增加“待确认”状态提示，不会自动删除词或历史。

### 快速成文

顶栏“快速成文”提供分步提示词。先复制第一步，把未导入的单词列表贴给第三方 AI；同一对话中等第一步完成，再复制第二步生成带中文释义的 Word 文档，最后手动导入软件。软件不会自动读取当前文章或发送内容。

“输出文件名”默认留空，AI 会按文章标题命名；填写时只需填一次，软件会自动补上 `.docx`。点击“管理提示词”可修改步骤名称和内容、新增第三步或更多步骤、删除及调整顺序。自定义提示词中的 `{{文件名}}` 会在复制时替换为当前文件名。配置保存在本机，取消编辑不会保存。

## 7. 快捷键与显示

| 操作 | 快捷键 |
|---|---|
| 下一个 / 上一个默写词 | Enter / Shift+Enter |
| 清空当前输入框并留在原处 | Shift+Backspace |
| 导入文章 | Ctrl+O |
| 原文 / 开始默写 | Ctrl+1 / Ctrl+2 |
| 提交批改 | Ctrl+Enter |
| 历史错词练习 | Ctrl+R |
| 专注模式 / 恢复原布局 | F8 |
| 放大 / 缩小正文及输入框 | Ctrl+滚轮、Ctrl++ / Ctrl+-，或工具栏加减按钮 |
| 恢复 100% | Ctrl+0 |

正文缩放范围 70%–180%，退出时记住比例。左右分栏可以拖动中间分隔线调整宽度；窗口可以最大化。缩放保留当前输入和焦点。

左侧顶部“收起文章列表”可隐藏文章栏；点最左侧“› 文章”可展开。退出后记住收起状态。右侧学习状态已缩窄，留出更多正文空间。

菜单栏新增“视图”：点击“专注模式”或按 F8，隐藏主工具栏和整个左侧文章栏，右侧学习状态及提交按钮保持不变。菜单栏始终可见，不在正文标题旁增加退出按钮；再点该菜单或按 F8，恢复进入前的工具栏、文章栏和分栏宽度。“视图”也可以分别开关工具栏和文章列表。退出程序记住手动设置，但不自动进入专注模式。大窗口中的正文限制适合阅读的宽度，不缩小字体，也不无限拉长每一行。

默写输入框不再重复显示“输入答案”；原边框、圆角、颜色和字号保持不变。初次排版、恢复草稿、缩放或重新聚焦时按实际字体测量答案与已填内容的宽度，并设上下限；输入过程中不逐字撑开或重排。超长答案可以在框内横向移动光标查看，保存内容不会截断。

在最后一个输入框按 Enter：有漏填题目时跳到第一个空白；全部填完时弹出“提交批改 / 继续检查”，默认选中“继续检查”，按 Esc 也可返回。只填完而不按 Enter 不会弹窗或自动交卷。Shift+Backspace 清空整个当前答案，普通 Backspace 仍逐字删除；提交后答案保持锁定。

正文和答案输入框已去除悬停提示，鼠标选中与 Ctrl+C 复制功能保留。

切换到下一个输入框时，如果题目接近可视区上下边缘，页面只做必要的小幅调整，留出后续上下文；已在舒适区域时不滚动。快速切换合并为最后一次跟随，不叠加动画；主动滚轮或拖动滚动条会取消尚未执行的跟随。缩放、显示/隐藏答案、切换专注模式时保留当前题附近的位置。正文中的英文和中文都可用鼠标拖动选中，再按 Ctrl+C 复制到浏览器查询。

“显示答案”无需确认，点一下在每个输入框旁完整显示答案，再点一下隐藏。正式提交后，写错或留空的题目也会在原句输入框旁直接显示红色的完整正确答案。

## 8. 导出与备份

选中文章后点击顶栏“导出”，选择“导出默写纸”或“导出答案版”，再选择**新的文件名**。

- 默写纸只替换目标英文，保留中文释义。答案版把目标英文标为红色加粗。
- 在 Word 副本上修改目标位置，尽量保留原字体、段落、表格和基本排版；程序内表格以阅读顺序显示。
- 原文件和内部缓存副本禁止作为导出目标，包括指向同一文件的链接。
- Word 被占用、目标与特殊对象共用文本块，或内容位置不一致时，停止导出并提示原因。

使用“导出 → 导出学习备份…”，将 ZIP 存在 `data` 文件夹之外。备份包括数据库、文章副本、手动调整、草稿、错词、历史和本地设置（包括快速成文内容），不含程序本身或外部原 Word。未选中文章也可备份；普通 Word 导出仍需当前文章。

恢复：使用“导入 → 恢复学习备份…”，选择以前导出的 ZIP。程序先检查路径、文件大小、数据库结构/完整性、草稿和文章副本；损坏或不兼容则停止。确认后关闭窗口，先自动备份并校验当前数据到实际数据目录旁的 `backups/recovery/恢复前学习备份-时间.zip`，成功后才整体替换并重新启动。恢复会替换全部当前学习数据和设置，不合并数据库；取消不替换数据。导入进行中不能备份或恢复。

恢复替换失败时回退原数据；若进程在替换中被中断，下次启动会先按恢复日志回退，再读取文章库。单实例锁保持到恢复结束，旧窗口不再保存输入，防止覆盖恢复结果。恢复前备份独立保存，不随数据替换删除。没有版本说明文件的旧版软件备份仍支持；文件安全限制为最多5000项、单文件128 MiB、总解压大小1 GiB，超出时拒绝恢复。非常旧的仅路径文章记录仍依赖原文件，无法凭空恢复未备份的原 Word。

旧版本可能留下没有对应错词的历史例句。恢复时会提示数量并原样保留，不擅自删除、合并或重建错词；正式成绩与答案关联损坏仍拒绝恢复。

本轮验证：230项自动测试通过，覆盖简洁入口、草稿恢复/取消、同篇多轮、第11篇清理、成绩保存失败保护、旧版备份兼容、损坏/危险路径拒绝、恢复前备份失败、替换回退及中断恢复。`tools/verify_focus.py` 检查100题长文章、焦点和宽窄窗口；`tools/verify_unfinished.py` 检查菜单和未完成列表；`tools/verify_recovery.py` 使用真实事件循环和单实例锁验证关闭/保存/替换/重新启动调用（最后启动调用模拟，不打开用户真实数据）。修改前程序、源码和完整学习备份在 `backups/before-unfinished-restore-20260930/`。
