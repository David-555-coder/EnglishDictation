# 英文文章智能默写 · 详细使用说明

本地优先的 Windows 学习工具。第一次在完整文章中回忆英文；手动交卷后统一批改；之后只复习错词所在的原句。学习、判题、复习算法和本地查词均可离线使用。只有主动选择“联网参考”并同意说明时，才会发送必要的所选英文及原句，不上传整篇文章或学习数据库，也不使用 AI API。

## 1. 启动与保存

双击 `EnglishDictation.exe`，不需要安装 Python，也不需要联网。

### 页面切换与性能（2026-10-24）

阅读本轮错词时，仅保留当前轮次的一份结果页面，返回时复用原来的只读答案和成绩显示，减少重复创建和排版；新练习、换文章或关闭窗口会释放保留页，不累计缓存多轮记录。缩放、阅读位置、划词复制及翻译继续可用，修改后的学习内容会在下一次错句阅读时重新读取。

相同几何布局不再反复放置所有控件，重复刷新结果也不会反复生成错词汇总。本轮只调整界面构建与复用，不修改文章、标准答案、判题、FSRS参数、每日选词或历史学习数据。性能对比使用同一学习数据快照的临时副本，离屏计时不等于所有电脑上的真实桌面帧率。

### 阅读时划词查译（2026-10-22）

在原文、错词原句预览、阅读本轮错词、提交后的结果中，划选英文并右键“翻译”。默认显示本地英汉词典，免费、免注册、免密钥。紧凑卡片可复制完整释义、展开长释义；点击卡片外部、按 Esc 或点 × 即可收起，卡片内选择/复制不关闭。联网结果单独使用“复制译文”，不会改变“复制释义”的对象。正在进行的默写不提供翻译。

小卡片里的“联网参考”为可选备用。首次会展示实际发送的英文和服务说明，确认后才查询；MyMemory 可能留存请求、有额度限制，且词组可能误译，不会代替词典、改题或改分。本地多义词显示常见义，不自动判断本句唯一词义；未收录完整表达时会明确提示。

查词组件首次使用时加载，后台查询、有限内存缓存、连续请求只保留最后一个待查内容，关闭或换页后旧结果作废。静态词库不放进单文件 EXE 反复解压，请保留 EXE 同级 `assets` 文件夹中的 `dictionary.sqlite3`、`dictionary_supplements.json` 和 `ECDICT-LICENSE.txt`。词库损坏或缺失只影响查词，不阻止学习软件启动。移动完整软件时保留这些公共资源；学习数据仍在原来的 `data`，备份功能和 FSRS 未改。

基础词库来源为 ECDICT，许可随软件保留；另有少量注明参考来源的补充释义。词库仍可能有漏词、旧义和不完整释义，不应把查到词条当成语境翻译准确的保证。

主目录的 `EnglishDictation.exe` 用于日常启动，`start.bat` 也会优先启动这个文件，继续使用原来的 `data`。无需重新导入。`src`、`tests`、`tools`、`packaging_hooks` 和打包配置保留供后续维护。

### 从 GitHub 获取与源码运行

在 Releases 下载最新 Windows 软件附件，完整解压并保留随包的 assets，再双击 `EnglishDictation.exe`。仓库仅提供软件，不包含个人文章库、答题记录或学习备份；首次使用时自行导入 Word 文章。

如需从源码运行，安装 Python 3.11 或以上版本，在项目目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

本地 `data`、日志、备份、构建产物和个人 Word 文件已由 `.gitignore` 排除，仍保留在本机。更新 EXE 和公共 assets 时，请保留自己的 `data` 文件夹。

请把 EXE 放在可写的普通文件夹中使用。学习数据默认在 EXE 同级的 `data`，日志在 `logs/app.log`。如果程序目录不可写，则使用 `%LOCALAPPDATA%/EnglishDictation` 下的 `data` 和 `logs`。

- 文章导入后，保存识别结果和一份本地 Word 副本。下次启动不用再导入；成功导入后，即使原文件移动，仍可学习和导出。
- 输入停止约 0.6 秒后自动保存草稿；切换文章、提交、关闭时也会保存。正常保存保持安静，只有保存失败才显示提醒。启动和点击文章列表时先显示原文，正常关闭后记住最后浏览的文章；没有对应文章时显示第一篇。草稿继续保留，从“练习 → 未完成练习…”手动恢复。主动点击“今日复习”仍续接当天已填答案；没有文章时显示今日复习状态。批改后保存失败的记录在未完成列表优先列出“成绩待保存”，打开后可重试保存。
- 程序自动保存最近更新的10篇未完成文章，从“练习 → 未完成练习…”明确继续；同篇多轮只显示最近一轮，已有同篇旧草稿不合并、不直接清空。超过10篇只清理最旧文章的整篇默写草稿，不删除文章、错词或正式成绩。错词/今日复习草稿仍按原有最近10轮规则独立保留，现可在同一入口按日期手动打开；旧复习草稿的正文标题也标明日期，不计作今天的新任务。
- 不要只搬走 EXE：换文件夹或换电脑时，请把 `data` 一起复制，或使用备份功能。
- 意外断电或强制结束可能丢失最后不到一秒尚未落盘的输入；正常关闭会保存。
- 同一份数据只允许一个程序窗口运行，避免互相覆盖草稿。

## 2. 导入与整理文章

1. 点击顶栏“导入”，选择“导入文章”可一次选多个 `.docx` 或旧式 `.doc`；选择“导入文件夹”则导入该文件夹内的 Word，不递归子文件夹。`.doc` 会在本机通过 Microsoft Word 转换成程序内部的 `.docx` 副本，原文件始终只读且不会被覆盖；电脑未安装 Word 时会给出中文提示。
2. 导入在后台进行，有进度提示。一个损坏文件不会阻止其他文件导入。
3. 左侧显示文章数、总重点词数和每篇重点词数，按文件名自然顺序排列，例如 `djc2` 在 `djc10` 前。
4. 可按文件名搜索；长文件名可悬停查看完整名称和来源路径。
5. 选中文章后，点“从列表移除”、按 Delete 或右键移除。确认后移除该文章及其草稿，但不会删除原 Word、学习历史或长期错词。缓存副本暂时保留，便于安全恢复。

支持拖动框选、Ctrl 点选不连续文章、Shift 选择连续范围。右键已选中的任意文章，选择“从列表移除选中的 N 篇文章”，也可点左侧底部“移除选中 N 篇”或按 Delete。一次确认、整批保存；发生数据库错误时不会只移除一半。搜索隐藏的文章不在移除范围内。

快速切换时会等待约 0.13 秒，仅读取最后选中的文章；多选整理期间不自动逐篇打开。原文在一张连续白色书页中按段落排版，保留重点词加粗与红色突出、中文释义、换行和可选中文字；默写和错词阅读继续按原来的学习单元组织。原文缩放时跟随正在阅读的段落，文章内容及存储格式保持不变。

旧版只保存了路径的文章，在第一次启动新版时会尝试读取原文件并建立副本。如果提示找不到文件，请找回原文件或重新导入。

修改外部 Word 不会自动改变已保存题目。要使用修改后的 Word，请先备份数据，再移除该文章并重新导入；该文章草稿会移除，历史记录保留。软件内保存的学习内容修正会在来源段落能可靠对应时保留；新 Word 已改变而无法对应的段落不会强行套用旧修正。

## 3. 挖空规则与手动调整

程序提供三个固定预设，默认使用标准模式。中文、标点、普通文字均保留；Word 的标题/Heading 样式默认不挖空。

- **标准模式（推荐）**：英文为红色或加粗，并且后面紧邻中文释义。
- **宽松模式**：不看颜色和粗体，只要英文紧邻中文释义就挖空。无格式短语的边界本身存在歧义，程序优先使用 Word run 边界；仍有少数识别不准时用“编辑学习内容”调整。
- **严格模式**：英文必须同时是红色且加粗，可以没有中文释义。

支持单词、连字符词、带撇号的词和完整短语；支持相邻 run 合并、圆括号/方括号中文释义和紧邻的中文注释。读取正文、表格文字、超链接显示文字，不访问链接。红色根据实际 RGB 或文档主题颜色判断，并考虑常见样式继承。

顶部“文章与设置”提供：

- **本篇识别规则**：在标准、宽松、严格三个预设中选择，对当前文章重新识别。
- **默认识别规则**：仅影响之后新导入的文章，不改已有文章。
- **编辑学习内容**：在文章预览中点蓝色词语，修改本句释义和可选易混备注；选英文设为挖空，或取消当前挖空。框选多个目标可合并并填写合并后的释义；“拆分短语挖空”按行填写英文及可选中文。“编辑本段”修改现有段落的中英文，应用后检查挖空范围；支持撤销和保存前预览。

这些修改只保存在软件里，不修改原 Word。新编辑器的修正按具体来源句段保存，同拼写在别句中的释义不一起替换；重新识别保留能对应的修正段落。旧版手动挖空仍会在重置前提示。当前轮次、旧草稿和历史成绩保留原题，新练习使用修正版。

编辑入口统一放在“文章与设置 → 编辑学习内容”。学习页面的文字可正常选择和复制，不提供右键修正或点击词语进入编辑。默写中从菜单进入编辑会先保存输入，并记录已显示答案；取消编辑也不撤销答案查看记录。源文章已从列表移除时，历史快照仍可修正已知词的释义和备注；正文和挖空调整需先恢复文章，避免覆盖快照未包含的题目。

原文、默写、结果、错词阅读和各编辑框的右键菜单采用统一中文与固定字号，不随正文缩放或词语颜色变化。阅读文字可复制所选或全选当前文本；可编辑输入框保留撤销、重做、剪切、复制、粘贴、删除和全选。提交后只读答案不提供可用的剪切、粘贴或删除。

易混备注在阅读和提交后显示，默写时隐藏。成绩标为“原词回忆结果”，仍按指定原词判分，暂不自动将近义表达判对。只改释义不清空原词记忆；更换英文目标不把旧词熟练度转给新词。取消某处挖空不删除整个词的历史记忆；后续复习优先使用其他可用例句，无可用题目时会明确提示。

普通正文样式的标题无法仅凭外观百分之百识别；若误挖，请手动取消。默认要求中文释义也可减少误判。

## 4. 第一次整篇默写

1. 选中文章，先用“原文”检查识别结果，重点英文显示红色加粗。
2. 点击右侧“学习状态”中的蓝色“开始默写”，显示完整文章，上下文、段落、换行、中文提示继续可见。
3. 填写英文。期间只显示填写进度，不显示对错或正确率。
4. 全部填完后仍可修改，不会自动提交。
5. 主动点击右侧蓝色“提交批改”。有空白会再次确认；确认提交后，空白算错误。

默写期间点“原文”（Ctrl+1）会先保存本轮输入，再切换原文，不会因为有草稿而拒绝查看。原文页右侧恢复为单一“开始默写”，Ctrl+2 同样开始新一轮；已有未完成练习时保留确认提醒，取消不会新开，也不清空旧草稿。继续已有输入请打开“练习 → 未完成练习…”，选中文章双击或点击“继续练习”，恢复答案和位置。仅查看原文不会产生草稿；全部填完但未提交仍算未完成。切换文章和启动均显示原文，不自动进入草稿。

答案比较忽略大小写、首尾空格、多余连续空格和常见弯直撇号差异，但不会自动修正拼写。例如 `Ambition` 正确，`ambitious` 错误。

提交后锁定本轮答案：绿色为正确、红色为错误；错误输入框旁完整显示正确答案，文章下方还有本次错词汇总。右侧显示正确数、错误数、未填写数、正确率。

如果数据库暂时写入失败，会提示“成绩待保存”。保持窗口打开，点击右侧主按钮“重试保存成绩”；同一轮不会重复累计。

“显示答案”控制提示的显示与隐藏，无需确认，不影响实际判分和错误次数。新版另外记录软件内的答案展示、原文预览和作答时间，用于区分独立回忆、阅读后答题和当日纠错。看答案后写对仍算答对，但不能据此假定已长期记住。显示答案前已填写、之后未改动的答案仍可保留回忆证据；之后修改过的答案不能恢复为“未看答案”。继续草稿时提示默认隐藏，但已记录的展示标记保留。旧版查看标记不用于推断过去是否盲测，历史成绩不追溯改写。

## 5. 错词复习：只练薄弱的句子

有两个入口：

- **只练本轮错词**：交卷后点右侧按钮，只生成刚才仍然写错的词。推荐读错句后隐藏答案、纠错重默一轮；剩余错误再读一遍即可，交给后续复习，不必当天反复练到全对。手动继续入口保留，但不会变成新的首轮回忆成绩。
- **历史错词练习**：打开历次有错词的提交记录，双击一条，或选中后点“开始练习”。可按完成时间或文章自然顺序排序；支持拖动、Ctrl、Shift 多选，并可通过右键、按钮或 Delete 批量删除记录。退出程序后未删除的记录仍保留。

进入错词复习后，程序会先显示一遍**带完整正确答案的错词原句**，目标词以红色加粗显示。阅读完成后点击右侧“开始错词默写”，才会把这些目标词换成输入框。这个准备预览不显示整篇文章，也不单独计算成绩。已经开始并自动保存的错词草稿，可从“练习 → 未完成练习…”继续填写。

例如原句 `The extensive research gained momentum.` 中只有 `momentum` 写错，复习时显示 `The extensive research gained [输入框].`，不会显示文章其他句子。

同一句中两个目标都错，会在一句内同时挖空；答对的目标正常显示。错词复习同样必须手动统一提交，不会即时反馈。

如果原文已从文章列表移除，历史错词仍能依据快照练习；但“开始整篇默写”和 Word 导出需要先导入完整文章。

## 6. 长期错词本与学习历史

点“错词本”可查看跨文章归并的词条，默认按字母排序，也可按错误次数或最近错误排序。支持搜索英文、中文，Ctrl/Shift 多选。

- 选中词条后点击“开始练习（N词）”：每个词选取一条保存的错误例句，组成句子复习；只练当前可见的选中词。没有选中词时，开始练习和删除按钮禁用。“练习全部错词”入口已移除。
- 展示相邻的英文、中文、错误次数、最近错误、来源、记忆状态和复习安排。文本列左对齐，日期、次数、状态居中，表头与对应内容一致。最近错误在表中显示简短日期，悬停可看完整时间；长英文和中文最多占两行，悬停保留完整文字。正确后不会擅自删除长期错词。
- 底部左侧“删除选中错词”，右侧“开始练习”和“关闭”。清空操作移到“文章与设置 → 数据管理 → 清空错词本…”。删除、清空都需要确认；清空删除长期词条及例句，不删除历史成绩。
- “练习”菜单恢复为“开始默写”“提交批改”，仅新增“未完成练习…”；“原文”和“显示/隐藏答案”继续在主工具栏，工具栏隐藏时可从“视图”重新显示。顶栏“历史错词练习”（Ctrl+R）继续提供有错词的历史练习入口，已有学习历史完整保留。

错误次数按实际错误答题记录累计。同一词在一轮出现多次并写错多次，会累计多次。当前没有统计整个文章库的总出现次数。

### 今日复习

顶部“错词本”旁的“今日复习（X）”显示今天已安排且尚未完成的不同词数。点击按钮直接默写；点击右侧小箭头，可打开“复习数量设置…”、“今天再加一些…”或“小组再练提醒…”。原“文章与设置 → 每日复习数量”入口也保留。沿用中文提示、原句、快捷键和统一批改，不新增考前或全面抽查模式。

2026-10-16起，数量改为**总量与其中的旧词上限**，不再把两组名额相加：

- **每天最多练多少词**：当天不同词的总量，可快捷选20、40、60、80、120，也可直接输入1–10000的整数。旧设置60加20会转为总量80，不偷偷加量。
- **其中，最多重新学多少旧词**：包含在总量内，不得超过总量。总量80、旧词上限20，若有74词需要按计划返回，则最多只加入6个旧词。旧词上限不是必做数；未到期词不补抽。自2026-10-23起，只按当天剩余名额加入旧词，不再用今天及未来三天的合计卡住加入。总量200、到期复习182、旧词上限40时，最多可加入18个旧词。练习页显示实际安排与每日上限，并按保存的选入原因显示“到期复习”和“加入旧词”。

设置默认保存为日常数量，也可勾选“仅今天调整”。尚未开始的预览可按新数量重新生成；已开始、已有草稿或已完成的任务保持稳定。明确增加额度时只在原清单末尾添加，原任务、完成状态和输入不动；降低数量不删已开始的任务，较小默认值从明天生效。有余力时用“今天再加一些”，只增加当天任务，不改变日常默认数量。填写本次最多追加N词、其中旧词最多M词，本次实际新增不会超过N，新增旧词不会超过M；先追加尚未安排的到期复习，不顺便补齐此前剩余的名额。同日已安排的词不重复抽取，删除的名额不自动补满。

错词本外层用“需要巩固／按计划复习／等待重新学习”。按钮悬停和设置说明实际待完成、已到时间仍未安排、等待重新学习的词数。“0”只代表今日计划已提交，不代表所有到期词已完成或全部记牢。详情可看原定日期、选入时间、原因和排队规则版本；不会为了界面好看而改写日期。

今日复习默认先独立默写，不预先显示答案。提交后弄懂错词、遮住英文尝试回忆，再完成一轮纠错。第二轮还有错且有余力，可约10分钟后“再练一组”：每组最多10词、每词每天最多额外一次，直接遮答案开始，提交后反馈，不重复占每日名额，中途关闭可恢复。提醒分钟数可以调整，不强制等待，不改变FSRS参数。新文章仍可先读一遍再默写。首轮、纠错与小组结果分开，不用纠错成绩覆盖首轮。

提交后可点击“阅读本轮错词”，直接在主文章区域阅读剩余错词的正确原句，蓝色突出目标词，保留中文和上下文；支持原有缩放和F8。右侧可“返回本轮结果”，恢复成绩与位置；也可主动开始下一轮。仅阅读不建立下一轮草稿，不消耗加练次数。“再练一组”可以选择1—10词；小组提交后可“返回原轮结果”，继续阅读或练剩余词。加练前的结果会随小组草稿保存，原轮成绩不会被覆盖。右侧状态栏按原文、默写、成绩和错词阅读显示相应信息；原文和错词阅读隐藏填写进度，快捷键提示跟随模式。缩放区与右栏对齐，滚动条旁留白收紧；保留自定义阅读字号。进度条仅表示填写情况，提交后显示“本轮已提交”。

记忆模型使用 **FSRS-7 的 34 参数双轨迹版本**，默认目标记忆率90%。推理核心移植自 [fsrs-rs 固定源码版本](https://github.com/open-spaced-repetition/fsrs-rs/tree/4bc0a0979f95dd01cc653031b6f2a01429e4c32b)，不是把 FSRS-6 改名。应用仅包含轻量推理，不安装 Rust、PyTorch 或训练模型。每个词保存慢/快记忆稳定性、难度、实际时间和可审计事件；通过官方 Rust 参考向量检验。符合证据条件的错误对应 Again，正确对应 Good，不按打字速度猜 Hard/Easy，也不新增四按钮评分。

各练习入口共用记忆记录。没有展示答案的真实回忆可以更新模型；有已记录尝试的当日闭卷纠错按真实分钟/秒间隔更新短期轨迹，而不是重复一次长期成功。阅读本身不打 Good，也不把未到期词判作失败。有效答错及纠错后尚待确认的词，到期日设为明天，但能否立即入选仍受每日容量限制；模型原始建议时间另存，供详情查看。为适应每天一次的词队列，其他有效回忆最早也在次日到期，不要求按分钟打开软件。90%是模型目标，不是固定40词下实际记忆率的保证。

新版提交记录保存纠错关联：关闭软件后，从“历史错词练习”打开刚提交的记录，仍可续接这一轮纠错并分别显示原首轮与纠错结果。模型只接受同一学习轮次、距该词最近有效尝试或已核实父轮失败不超过24小时的闭卷纠错；答题中再次展示答案、其他练习已更新该词或时间倒退时不会凭空增加模型信用。开始前的原句预览与答题中查看答案明确区分，即使两次操作碰巧具有相同时间戳，也只豁免本轮已记录的预览。旧版没有关联的记录仍可练习和计分，但不倒推不存在的证据，也不补改历史成绩。

已有记忆状态的词，如果本轮读后答错而未更新模型，后续闭卷纠错会核实实际失败的父记录、原学习轮次、先后时间和是否被其他尝试取代。关联有效且距失败不超过24小时，才以这次真实失败为短期重学起点，再更新当前纠错状态；不会把它误算成间隔多天的独立答对。原失败事件和历史成绩不改写，当前记录另外保存采用的失败关联。缺失父记录、成功父记录、看答案、过期、时间倒退或关联被取代时不授予这项模型更新。

每日队列保留 [Anki 的分流原则](https://docs.ankiweb.net/filtered-decks.html#catching-up)，但不是完整复制分钟级学习步骤。使用明确、持久的“已加入持续复习”记录，不再靠最近7天临时分组。首次升级只衔接最近实际学习日的有效模型词及已有未来安排，其他旧词分批加入，**模型参数与日期原样保留**；已开始的旧清单保留。开始今日任务、真实有效练习或实际读后失败需要确认时会纳入持续复习，纯阅读不会升级。

持续复习的到期词先按保存的应用复习日期返回，日期平手再比较FSRS回忆风险；不会因昨天刚完成就排到大量旧词后面。剩余容量才考虑旧词上限。明天、后天、大后天的已知到期数分别展示，只作提醒，不用跨天合计限制今天的旧词加入；如有一天已超过日常上限，会建议先照顾已有复习。这里只统计当前已排定的词，今日作答、旧词加入后仍会变化，不是准确的总工作量预测。不自动改变每日数量、FSRS参数或记忆日期。

如果持续复习需求已超出总量，旧词暂缓加入，界面如实提示缺口；未选中词不删除、不自动升级、不偷偷推迟日期。不会承诺在不断失败且时间不足时，还能快速清空所有旧词。

各练习共用记忆记录。其他入口的合格独立回忆会同步完成已有今日任务；短时纠错不能冒充下一天的独立任务。看答案后完成今日答题会消耗原槽位，但仍等待独立确认。跨日旧今日草稿只保存成绩，不更新模型或当天计划。跨午夜的一小时内近期阅读仍按读后作答，刚练过的短时回忆不会仅因日期变化变成长期成功；正常隔夜独立回忆不一律封锁24小时。一小时是保守的证据规则，不是经过个人校准的遗忘界限。其他界面答题中看答案也会校验；展示前已填写的有效答案保留证据。

这轮解决的是连续复习被旧词挤走和证据误计，不是保证正确率的捷径。真实效果仍需后续未提前看答案的首轮记录验证；排队模拟不能证明学习效率已提高。

升级前自动备份旧数据库到 `data/migration_backups/`，只增量增加记忆字段、事件表和展示记录表，保留旧成绩、草稿、文章和已生成的当天任务。已有错词到期日保留，旧记录不假装成盲测数据；遇到下一次有证据的回忆时才建立新模型。没有新版证据标记的旧草稿可继续判分，但不能用于拉长记忆间隔。尚无日期的更早期错词仍沿用分批初始化，避免全部同时到期。

Cost ADR 暂未启用，不训练参数或降低目标记忆率。`tools/verify_review_continuity.py` 在独立副本上重放实际漏练词，并按40/80/120总量、低成功率和漏学日做28天容量检查；不写正式学习数据。旧版`verify_review_streams.py`及旧选择函数只用于历史兼容重放，桌面实际运行的是`review_continuity`策略，不同时混用两种排队算法。

## 8. 导出与备份

选中文章后点击顶栏“导出”，选择“导出默写纸”或“导出答案版”，再选择**新的文件名**。

- 默写纸只替换目标英文，保留中文释义。答案版把目标英文标为红色加粗。
- 在 Word 副本上修改目标位置，尽量保留原字体、段落、表格和基本排版；程序内表格以阅读顺序显示。
- 原文件和内部缓存副本禁止作为导出目标，包括指向同一文件的链接。
- Word 被占用、目标与特殊对象共用文本块，或内容位置不一致时，停止导出并提示原因。

使用“导出 → 导出学习备份…”，将 ZIP 存在 `data` 文件夹之外。备份包括数据库、文章副本、手动调整、草稿、错词、历史和本地设置（包括快速成文内容），不含程序本身或外部原 Word。未选中文章也可备份；普通 Word 导出仍需当前文章。

恢复：使用“导入 → 恢复学习备份…”，选择以前导出的 ZIP。程序先检查路径、文件大小、数据库结构/完整性、草稿和文章副本；损坏或不兼容则停止。确认后关闭窗口，先自动备份并校验当前数据到实际数据目录旁的 `backups/recovery/恢复前学习备份-时间.zip`，成功后才整体替换并重新启动。恢复会替换全部当前学习数据和设置，不合并数据库；取消不替换数据。导入进行中不能备份或恢复。

恢复替换失败时回退原数据；若进程在替换中被中断，下次启动会先按恢复日志回退，再读取文章库。单实例锁保持到恢复结束，旧窗口不再保存输入，防止覆盖恢复结果。恢复前备份独立保存，不随数据替换删除。没有版本说明文件的旧版软件备份仍支持；文件安全限制为最多5000项、单文件128 MiB、总解压大小1 GiB，超出时拒绝恢复。非常旧的仅路径文章记录仍依赖原文件，无法凭空恢复未备份的原 Word。

旧版本可能留下没有对应错词的历史例句。恢复时会提示数量并原样保留，不擅自删除、合并或重建错词；正式成绩与答案关联损坏仍拒绝恢复。
