# 界面外观讨论

日期：2026-10-18。状态：用户回复“全按推荐”，已确认下列方向，现已完成实现、验证及主目录EXE更新。

## 已有行为与约束

- “导入”的蓝色圆角框来自工具按钮的焦点样式。临时数据与离屏窗口验证：启动显示后默认焦点落在导入按钮，恢复文章后仍保留。
- 单独收起文章列表保留顶部工具栏；F8同时收起顶部工具栏及文章列表，并在退出时恢复先前布局。两者用途不同。
- 当前已有“视图 → 显示文章列表”入口。即使移除整行折叠按钮，仍可保留单独显示/隐藏左栏的能力。
- 移除旧入口时需兼容原折叠设置、恢复布局，避免留下无展开按钮的空条。
- 原文阅读、错词阅读与专注模式的含义记录于根目录CONTEXT.md。外观调整不应改变这些学习行为。

## 已确认的方向

1. 原文阅读区采用连续书页；默写和错词阅读仍按其学习单元组织。保留原文内容、重点词、中文与用户字号。
2. 删除整行折叠按钮，不另外增加标题图标；保留“视图 → 显示文章列表”及F8。

## 已确认的外观目标

- 启动与鼠标操作时不突出导入按钮的外框；键盘导航时保留清楚但克制的焦点提示。
- 统一中性底色、边框强度、字体层次、按钮和留白，保留用户的阅读字号及已确认的学习流程。
- 上述外观选择成本较低且可逆，不建立架构决策记录；后续实现不改变学习流程、判分及复习安排。
