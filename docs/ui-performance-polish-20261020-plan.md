# UI 与复习主流程性能精修方案

日期：2026-10-20。状态：已实施、验证并更新日常 EXE；详见 qa/ui-performance-20261020-185636/verification.md。

## 用户已确认的取舍

- 保留现有布局与按钮位置，精修质感，不整体重设计。
- 优先今日复习 → 提交结果 → 纠错 → 阅读本轮错词 → 返回结果。
- 继续沿用 CONTEXT.md 中的“今日计划”“每日总量”“错词阅读”等定义；本轮不改变学习领域概念，不向术语表加入通用 UI 或性能术语。

## 不变的边界

- 不改 FSRS 公式、参数、复习日期规则、选词顺序、每日数量设置、判分规则和学习证据含义。
- 旧词上限与每日总量的包含关系、已开始计划不重抽等语义不变。
- 保留跨句复制、隐藏答案保护、所有适用快捷键、草稿恢复、排序记忆、输入焦点与滚动锚点。
- 显示缩放保留在右上角，导入与导出相邻；不靠缩小正文或输入框来增加空间。
- 不删除兼容代码、不更换 UI 框架、不无限缓存页面、不增加装饰性动画。

## 只读检查发现与候选改动

本轮尚未运行性能测试。以下代码事实不等同于已证实的用户可感知卡顿。

### 视觉和易用性

1. 结果右栏有重复信息：完全独立答题时，“首轮回忆”与“本轮答题正确”可能重复。精简重复文案、调整主次层级，但首轮和纠错结果必须分别保留，不合成一个正确率。
2. 易混备注与正文被统一缩放为同级字号。给备注单独的视觉层级，保留内容、复制顺序和阅读清晰度，不整体缩小正文。
3. 排序框、数量输入框、菜单与按钮的边框和状态样式未完全统一。仅提取必要的共享样式，保持位置、点击区域和键盘反馈。
4. 错词本搜索无结果、历史列表为空时缺少明确反馈。复用现有位置提供简短空状态，不新增大面板或移动按钮。

参考位置：src/ui/main_window.py:1426、1908；src/services/learning_evidence.py:126；src/ui/dialogs.py:127、323；src/ui/daily_review_dialog.py:34。

### 性能：先测再改

1. 优先减少构题时的重复读取和解析：候选词逐个调用例句解析，每次重新读取全部内容修订；最终构题又会读取选中题目。候选方案是单次事务内复用解析上下文、批量读取必要记录。
2. 有内容修订时，例句查询会读取更多历史记录，备用例句查找还可能逐词重新解析文章快照。评估延迟读取和单批快照索引，不能直接恢复只取一条历史例句的旧逻辑。
3. 一次提交或首页刷新可能多次读取今日状态。评估单次交互共用状态快照，写入完成或跨日后重新读取，不使用长期陈旧缓存。
4. 阅读错句与返回结果会销毁并重建内容。先测耗时和内存；仅在收益明确时做局部复用，不先引入双页面长期缓存。
5. 长页面拖选会逐次扫描片段；输入每个字符会重新统计填写数。作为次优先候选，只有测量确认值得做才改；真实答案、作答证据时间和自动保存不能合并丢失。

参考位置：src/services/review_continuity.py:134；src/database/repository.py:909；src/services/learning_content.py:216；src/ui/main_window.py:1593、1741、1908；src/ui/widgets/reading_selection.py:191。

已有优化应保留，不作为本轮新增成果：无变更草稿去重、答案/视图分别延迟保存、切文合并、滚轮缩放合并、文章按需加载、布局高度缓存、批量结果摘要、关闭对话框销毁。

## 实施与验收顺序

1. 先备份、记录构件与数据哈希；在独立数据库副本建立基线，不初始化或迁移正式学习库。
2. 使用相同数据分别检查 120、200、300 词负载，覆盖有/无内容修订、不同缩放和窗口宽度。
3. 记录进入复习、提交、纠错、阅读与返回的耗时；重复测量比较中位数、较慢分位、UI 事件处理停顿、SQL/解析次数和内存回落。
4. 先实施已确认收益的低风险精简，再做必要视觉调整；收益不明确的重构不纳入。
5. 对比同样操作下的入选词 ID 与顺序、题面、答案、成绩、记忆事件、到期日期；内容修订、取消挖空和备用例句场景须保持等价。
6. 检查连续复制、隐藏答案、快捷键、未保存输入、关闭重开、排序、缩放和滚动恢复；对比不同模式的截图。
7. 完成源码与候选 EXE 验证后，正常关闭正式软件再更新；不强制结束进程，不对外发布。

离屏 Qt 测试只能证明对应场景和改前改后比较，不等同于原生桌面帧率、多显示器验证或绝无缺陷。验收结果应分别报告功能、视觉、性能和仍需实际桌面确认的部分。

## 本轮文档决策

这些是可逆的局部精修，不为它们新增 ADR。若测量结果要求更换正文渲染方案、虚拟化或长期页面缓存，应另提替代方案和兼容风险，再请求确认。
