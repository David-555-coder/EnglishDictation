# 随读词典：独立原型第二版

本目录只是可行性验证，不会被正式软件的 `app.py` 导入。

## 直接试用

解压 `qa/dictionary-prototype-20261022-1927/随读词典-独立试用.zip`，
打开其中的“随读词典-独立试用.exe”。EXE、dictionary.sqlite3 和补充释义文件需保持在同一文件夹。
这是独立程序，不会替换 EnglishDictation.exe，也不读取学习数据库。

1. 选中单词或词组，右键“翻译”，直接查看本地词典释义，不需要联网或注册。
2. 小卡片突出词条和中文，音标/来源弱化；可复制、展开全部、点 × 或 Esc 关闭。
3. 本地未收录完整词组会明确提示，不会把单词释义拼在一起冒充整词组翻译。
4. 偶尔需要在线参考时，再点卡片底部“联网参考”。第一次会展示实际发送的英文，确认后才查询。

可切换两组示例，也可临时粘贴自己的英文。默认查词不上传任何文字；粘贴内容不落盘。
不要粘贴保密内容：在线服务可能保留请求，亦可能使用外部机器翻译供应商。
“独立默写”只是禁用翻译的演示状态，没有真实判分或练习记录。

## 质量边界

本地词库基于 ECDICT 基础版，另有少量单独注明来源的补充释义。
词库有过时、遗漏和多义不全的问题，不会自动判定本句唯一词义。
MyMemory 仅作手动备用，部分习语会明显误译，不会自动覆盖词典结果。
默认不自动修改原文释义、成绩、单词或复习算法。

完整结果见 `qa/dictionary-prototype-20261022-1927/验证报告.md`。
上一版机器翻译的原始评估保留在 `qa/translation-prototype-20261022/`，不把它的结论混作词典质量证明。

## 维护与验证

词典只读查询和后台任务放在 `dictionary.py`，联网备用在 `engine.py`，独立界面在 `ui.py`。
没有 WebEngine、网页抓取、账号、密钥、后台常驻进程或新增正式依赖。
本地和联网查询均有 128 项内存缓存；联网缓存保留一小时，关闭原型后不保留。
一次只发一个请求，8 秒超时，不自动重试，不切换镜像绕过限额。
联网严格遵守服务单次 500 UTF-8 字节、同一段落的限制，不截断或拆段偷偷发送。
首个网络请求时才创建 Qt 网络对象；TLS 校验保持开启。

开发环境中也可运行本目录的“启动原型.ps1”，或在既有依赖路径下运行：

```text
python -m tools.translation_prototype.ui
python -m pytest -q -p no:cacheprovider tools/translation_prototype/test_prototype.py
```

联网样例工具 `evaluate.py` 只使用 `samples.json` 中的自拟英文，不读取用户文章。
`assess_dictionary.py` 记录词典覆盖和实际释义，`smoke_dictionary.py` 做离屏原型观察。
`build_dictionary.py` 只在维护阶段预生成索引，不在启动时执行，也不覆写已有词库。
`evaluate_offline.py` 仅用于历史比较官方 Argos 1.9 英译中模型与最小 CTranslate2 运行方式；
离线实验的依赖和模型只位于 QA 目录，没有装入正式软件或原型 EXE。

原型 EXE 的 `--verify-prototype <输出目录>` 验证本地词库和回环假服务，完成后正常退出，
不访问外网，也不访问正式学习数据。
